# Source and handoff contract

The supplied source inputs are administrative/reference-zone shapefiles, annual FIRMS MODIS/VIIRS detections and the retained c3 annual CSV bundle under `rp1_gee_ba_scripts/downloads/c3_release/`. Generate new burned-area CSVs only with the pinned `rp1_gee_ba_scripts/c3/` applications. Each annual per-zone district or ACZ file contains all 69 fields of `rp1_ba_c3_extended_v2`. The BA2001 and BA2012 fixed unions require 370 analytical files for the full selected delivery; a declared 2024 pilot requires 20. Optional inventory/boundary records are operational evidence, not analytical tables. Other operational downloads remain excluded. Preserve original source bytes and provider attribution. Hashes establish local byte identity, not independent data accuracy or Earth Engine asset content.

The selected geography run supplies district and zone identities, whole-district boundaries, projected analysis derivatives, a district-to-zone crosswalk and QA. Active-fire panels must use those boundaries. The c3 upload bundle has three combined EPSG:32630 layers mapped to `C3.ghanaAsset`, `C3.zoneAsset` and `C3.districtAsset`; c3 reductions retain the declared native MODIS grid. Record approved remote asset/version evidence, script hashes and monthly/annual source indexes alongside local identities. The merger must verify the admitted c3 handoff and its annual file matrix, selected geography and active-fire source. The analysis handoff contains only matching outputs, mandatory full c3 evidence, manifests, geometry and crosswalk identities.

Missing files, duplicate keys, incompatible schemas, absent source images or withheld primary values must not become zero. The source key is `(ba_domain, level, unit_id, yyyymm)`. Admitted c3 rows retain the adopted zero contribution for unaccepted evidence, including `NO_SUPPORTED_EVIDENCE`; this is an analytical scenario, not observed fire absence. Primary anomaly/unresolved/technical nulls and independently guarded annual denominators remain distinct. `ba_supported_fraction` is conditional on qualifying visible evidence, not observation coverage. The annual union-numerator/annual-denominator ratio can exceed one. Source-mask representation, local/remote geometry and full-period source qualification remain separate from a successful software run.

Generate analytical populations from configured eligibility rules. Record realised populations, exclusions and source hashes. Regenerate all dependent analyses when a scientific input or method changes; do not substitute hashes or operator acknowledgement for actual regeneration and source-bound validation.
